# **App Name**: FormFlow

## Core Features:

- Form Builder: Drag-and-drop interface for creating and customizing forms with various question types (short answer, paragraph, multiple choice, checkboxes, dropdown, file upload).
- Form Sharing: Generate shareable links and QR codes for easy form distribution; responses collected without requiring login.
- Response Management: View, filter, and export form responses to Excel or CSV formats for analysis.
- Dashboard Analytics: Interactive dashboards display key metrics (total forms created, responses collected, active vs inactive forms) and recent form lists.
- AI-Powered Form Tailor: AI tool that provides suggestions to tailor forms and question types for different audience.
- Access Control: Role-based access control to protect sensitive information and ensure the right users have the appropriate access levels.

## Style Guidelines:

- Primary color: Light blue (#64B5F6), evokes trust and stability, important for data-driven applications.
- Background color: Very light gray (#F5F5F5), ensures comfortable readability and a clean aesthetic.
- Accent color: Light green (#81C784), provides contrast for key actions and elements without being too aggressive.
- Body and headline font: 'Inter', a sans-serif typeface with a modern, neutral appearance that works well for both headlines and body text.
- Use a consistent set of simple, outline-style icons to maintain a clean and modern interface.
- Implement a clean, organized layout with a left sidebar for primary navigation and a top navbar for user-specific actions (search, notifications, profile).
- Use subtle transitions and animations to provide feedback on user interactions and enhance the overall user experience.
